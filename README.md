# DevOrbit – National Weather Big Data Analytics Platform

## Project Overview
DevOrbit is a centralized weather-data platform designed to collect, validate, and manage weather records from multiple sources. It helps identify duplicate and inconsistent data and improves data quality.

## Objectives
- Centralize weather data from different sources.
- Validate weather records.
- Detect duplicate and inconsistent data.
- Improve data processing efficiency.
- Display validated data through a dashboard.

## Key Features
- Centralized weather-data management
- Data validation
- Duplicate detection
- Data processing using Python
- Dashboard for viewing weather data

## Technologies Used
- Python
- Data processing libraries
- Web dashboard
- Centralized data storage

## Testing
Testing was completed by comparing the automated platform with manual checking using the same dataset. Processing time, duplicate detection, and data quality were evaluated.

## Limitations
- Results depend on the quality of input data.
- The platform does not provide official weather forecasts.
- It does not provide emergency alerts.
- Further testing with larger datasets is required.

## Future Enhancements
- Integrate more weather-data sources.
- Improve data validation methods.
- Enhance dashboard design.
- Support larger datasets.
- Collect stakeholder feedback.
